# Mockups de diseño (legado)

Esta carpeta contiene las pantallas HTML/PNG generadas en la fase de diseño visual del
proyecto (Stitch). **No forma parte del runtime** ni la carga `index.html`.

Se conserva como referencia histórica de la evolución de la interfaz. La aplicación
funcional es el `index.html` de la raíz del repositorio, con assets en `../vendor/`.

Puedes eliminar esta carpeta si no necesitas las referencias de diseño.
