Generador de licencias · NG_MACROS

Firma licencias ECDSA P-256 con fecha de vencimiento y crea el enlace para compartir.

La clave privada es el secreto más importante. No la subas a GitHub, no la envíes por chat y guarda una copia de seguridad. Si la pierdes, no podrás emitir nuevas licencias; si se filtra, cualquiera podrá generarlas. Esta página funciona en tu navegador: la clave privada no se envía a ningún servidor.

1. Clave privada

Carga tools/license-private-key.json o pega su contenido. También puedes crear un par nuevo.

2. Datos de la licencia

El enlace tendrá la forma https://tu-sitio/index.html?lic=TOKEN.

3. Resultado

4. Verificar una licencia

Pega un token y la clave pública del proyecto. La verificación se hace sin conexión.

Cómo usarlo

  • Ejecuta una vez node tools/license-generator.mjs keygen si aún no tienes claves.
  • La clave pública ya está embebida en index.html. Si generas un par nuevo, actualiza LICENSE_PUBLIC_KEY.
  • Genera la licencia, copia el enlace y envíalo al cliente. Al abrirlo, la app guarda la licencia en el navegador.
  • La licencia caduca automáticamente en la fecha indicada. El cliente puede seguir usando la app en modo demo, pero no exportar G-code.
  • Para renovar, genera un token nuevo y comparte un enlace nuevo.
  • Esto es una app estática: la firma y la fecha se verifican en el navegador. Un usuario con conocimientos técnicos podría modificar el HTML o el reloj. Para una protección fuerte hace falta validación en servidor.
